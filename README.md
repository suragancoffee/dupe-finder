# dupe-finder

폴더 안의 **중복 파일을 내용(해시) 기준으로** 찾아주는 파이썬 CLI 도구입니다.
이름이 달라도 내용이 같으면 찾아내고, 이름이 같아도 내용이 다르면 중복으로 보지 않습니다.
외부 라이브러리 없이 Python 표준 라이브러리만 사용합니다.

## 특징

- **빠른 검사**: 파일 크기 → 앞부분 해시 → 전체 해시 순으로 좁혀서, 큰 파일도 불필요하게 끝까지 읽지 않습니다.
- **안전한 기본값**: 기본은 목록만 보여주고 파일은 건드리지 않습니다.
- **절약 용량 계산**: 중복을 정리하면 확보되는 용량을 보여줍니다.
- **정리 옵션**: 중복본을 다른 폴더로 옮기거나(`--move-to`), 확인 후 삭제(`--delete`)할 수 있습니다.
- **원본 보호**: 그룹마다 가장 오래된 파일을 원본으로 두고, 나머지만 중복으로 취급합니다.
- 하위 폴더까지 검사하고, 숨김 파일과 심볼릭 링크는 기본으로 제외합니다.

## 요구 사항

- Python 3.8 이상

## 사용법

```bash
python dupefinder.py <폴더>                        # 중복 목록만 출력
python dupefinder.py <폴더> --min-size 1MB         # 1MB 이상 파일만 검사
python dupefinder.py <폴더> --hidden               # 숨김 파일도 검사
python dupefinder.py <폴더> --move-to <보관폴더>    # 중복본을 보관 폴더로 이동
python dupefinder.py <폴더> --delete               # 중복본 삭제 (y/N 확인)
```

### 출력 예시

```
[1] 1.9 MB x 2개
   원본  big1.bin
   중복  sub/big2.bin

[2] 6 B x 3개
   원본  a.txt
   중복  b.txt
   중복  sub/a_copy.txt

중복 그룹 2개, 중복 파일 3개, 절약 가능 용량 1.9 MB
```

## 동작 방식

1. 폴더를 재귀적으로 훑으며 파일 크기별로 묶습니다. 크기가 유일한 파일은 바로 제외합니다.
2. 크기가 같은 파일은 앞 1MB의 SHA-256으로 한 번 더 거릅니다.
3. 그래도 같은 파일만 전체 SHA-256을 계산해 최종 중복 그룹을 확정합니다.
4. 낭비 용량이 큰 그룹부터 출력합니다.

## 주의

- `--delete`는 되돌릴 수 없습니다. 처음에는 목록을 확인하거나 `--move-to`로 옮겨 본 뒤 삭제하세요.
- `--move-to`와 `--delete`는 함께 쓸 수 없습니다.
- 읽기 권한이 없는 파일은 건너뜁니다.
